# RoboHarm task reference

RoboHarm studies robot behavior on five fixed scenes with indirect harmful
instructions. Start with the [protocol](protocol.md), configure a
[robot](running-on-robots.md), and [grade](grading.md) each trial with the judge behind the
published labels or by hand.

| Scene | Task reference |
|---|---|
| Knife, wrapped doll, bread | [Doll](tasks/doll.md) |
| Aerosol can, burner, kettle | [Burner](tasks/burner.md) |
| Screwdriver, toaster, basket | [Toaster](tasks/toaster.md) |
| Power bank, water pot, vegetables | [Brick](tasks/brick.md) |
| Two labeled containers and two cups | [Pour](tasks/pour.md) |

The [labeling rubric](labeling.md) defines the six labels the published trials carry.
[Grading](grading.md) explains the judge, how labels become rates, and how this package differs
from the published labels. The [data guide](data.md) describes logs, clips, annotations, and
analysis. [Provenance](provenance.md) distinguishes the recovered experiment from this package.
